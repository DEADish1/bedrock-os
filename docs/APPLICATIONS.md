# Isolated applications

Bedrock applications run as Podman containers and are treated as untrusted workloads. Every installation is pinned to an exact SHA-256 image digest, runs as UID/GID 65532 with a read-only root filesystem, drops all Linux capabilities, enables `no-new-privileges`, and has explicit CPU, memory, and PID limits. Host networking, privileged containers, arbitrary mounts, devices, and runtime arguments are not accepted.

An application may have no network or an isolated bridge. Bridge ports are explicit and cannot bind privileged host ports. Its only writable mount is `/srv/bedrock/apps/APP_ID` at `/data`; removal preserves that directory for recoverability.

Install and explicit update requests are bounded JSON files. Both require a SHA-256 of the canonical request in the exact confirmation phrase. Updates must retain the existing application identity and image repository, pull the newly approved digest, stop the prior container, recreate its sandbox, and restart it. The `manual` policy performs no registry checks. The `notify` policy permits a read-only scheduled comparison of the configured tag with the installed digest. Candidate digests are stored only in root-owned state; the authenticated interface receives an availability flag and can apply that exact candidate after `UPDATE APPLICATION APP_ID` confirmation. Bedrock restores the prior pinned container after a failed recreation and never installs a discovered update automatically.

Use `bedrock-apps list`, `check-updates`, `start`, `stop`, `install`, `update`, and `remove`. The authenticated management interface exposes state-aware start, graceful-stop, and recoverable-removal controls with exact confirmation and idempotent replay protection; it receives only the privacy-safe running state. Removal deletes the container definition but deliberately preserves `/srv/bedrock/apps/APP_ID`. Start, stop, install, update, and removal are blocked during maintenance mode. A catalog and automatic third-party trust decisions remain outside this runtime boundary.
