# Security policy

Bedrock is pre-release and has no supported production version yet. Security fixes target the newest development branch and may require replacing an image rather than applying an in-place package update.

Report suspected vulnerabilities through [GitHub private vulnerability reporting](https://github.com/DEADish1/bedrock-os/security/advisories/new). Include affected versions or commit IDs, impact, prerequisites, and minimal reproduction details. Do not include real credentials or personal data. Do not open a public issue until maintainers confirm that coordinated disclosure is complete.

Receipt and remediation times are not guaranteed during pre-release development. Maintainers will validate the report, establish severity and affected releases, coordinate a fix and disclosure when appropriate, and credit reporters who request attribution. Cryptographic-key exposure, authentication bypass, unsafe disk targeting, update-signature bypass, remote plaintext exposure, and escape from a VM or application boundary are release-blocking classes.
